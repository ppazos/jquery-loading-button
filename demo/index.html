Click each button several times, as an impatient user would. The counter shows how many requests the page would have sent. The forms submit to a hidden frame that never answers back, so the page behaves like it is waiting for a slow server. Use Reset to try again.

Without protection

A plain form

Every click sends a request.

Plugin: loading-button.js

These forms opt out of the guard, so only the plugin acts on them.

Spinner on click

$(button).loading(). Click several times, then focus the field and press Enter: only one request is sent.

Form validation

With the field empty, Send shows the browser message and no spinner. Save draft has formnovalidate, so it submits anyway.

AJAX request

The page stays, so the code calls loading('stop') when the request ends (2 seconds here).

Start and stop from code

loading('start') and loading('stop').


Guard: form-submit-guard.js

No JavaScript is needed for these forms: including the script is enough.

Protected form

Click several times, or press Enter in the field: only one request is sent.

Submit cancelled by the page

While the box is checked, the page cancels the submit and the form stays usable.


Button outside the form

A button linked with the form attribute is protected too.

Opted out form

Forms with data-no-submit-guard, such as file downloads, are not locked.
